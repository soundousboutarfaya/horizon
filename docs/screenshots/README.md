# Screenshots

Drop your own captures here so they show up in the main `README.md`.

Expected files (referenced by the README):

| File         | What to capture                                              |
| ------------ | ----------------------------------------------------------- |
| `map.png`    | The home page with the interactive map and a few markers    |
| `form.png`   | The "report a problem" modal/form                           |
| `admin.png`  | The admin panel (`/admin`) with the reports table           |

## How to capture

1. Start the app: `npm start`
2. Open http://localhost:3000
3. Take a screenshot (macOS: `Cmd + Shift + 4`, then drag).
4. Save it here with the exact filename from the table above.

Tip: a short animated GIF of the map interaction (saved as `demo.gif`) makes a
great hero image — link it at the top of the README if you record one.
